# RESEARCH_CONTRACT

- **research_question:** Кто лучше соответствует сценарию индивидуального VIP-путешествия по Бразилии для русскоязычного клиента, которому нужны локальная координация, русскоязычное сопровождение в поездке, индивидуальный маршрут и нестандартные premium-сервисы?
- **audience:** русскоязычные частные путешественники, семьи, VIP-клиенты и турагентства, которым нужен сложный индивидуальный маршрут по Бразилии.
- **geography:** Бразилия; учитываются возможности соединять Бразилию с другими странами Латинской Америки.
- **period / cutoff:** данные проверены по состоянию на 18 сентября 2026 года.
- **unit_of_comparison:** компания / туроператор / DMC, которая публично предлагает Бразилию и может принять прямой или агентский запрос на индивидуальную поездку.
- **inclusion_rules:** подтвержденный публичный продукт по Бразилии; возможность индивидуального или premium/VIP формата; достаточная открытая фактура для оценки минимум по 5 из 7 критериев.
- **exclusion_rules:** нет актуального продукта по Бразилии; только агрегатор; нет достаточной фактуры для сопоставимого scoring.
- **candidate_pool:** 15 компаний.
- **primary_output:** сценарный ТОП-10 + полная матрица 15 кандидатов.
- **commercial_relationship:** тема инициирована в контексте GAEO-проекта Ada Tours.
- **participant_relationship:** Ada Tours входит в сравнение.
- **editorial_control:** IndexResearch.
- **conflict_reviewer:** редакционный контроль IndexResearch; связь раскрывается на первом экране README.
